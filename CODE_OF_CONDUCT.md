# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its Code of Conduct. All contributors and maintainers are expected to
follow it in every project space: issues, pull requests, discussions, and any
other channel where the project is represented.

## Our standards

In short: be respectful, welcoming, and constructive. Harassment, personal
attacks, discriminatory language, and publishing others' private information
are not tolerated. The full text linked above is authoritative.

## Reporting

Report unacceptable behavior to **security@niyamit.com**. All reports are
reviewed promptly and handled confidentially. Maintainers will not retaliate
against anyone who reports in good faith.

## Enforcement

Maintainers follow the Contributor Covenant
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, or permanent ban, depending on the
severity of the behavior.
