# sphere-data

Lookup tables and damage curves used by SPHERE.

The `damage_curves_*.csv` and `df_lookup_*.csv` files are a point-in-time fork
of the damage functions in
[Inland Consequences](https://github.com/fema-ffrd/inland-consequences)
(MIT, Copyright (c) 2025 fema-ffrd), now maintained in SPHERE. Their license is
in `src/sphere/data/LICENSE-inland-consequences`. See `THIRD_PARTY_NOTICES.md`
at the repository root for the commit they were forked from.
