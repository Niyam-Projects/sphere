# Security Policy

## Supported versions

Only the latest released version of SPHERE (`niyamit-sphere`, `sphere-core`,
`sphere-data`, `sphere-flood`) receives security fixes.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Report privately through either channel:

- GitHub: use **Report a vulnerability** on the repository's
  [Security tab](https://github.com/Niyam-Projects/sphere/security/advisories/new).
- Email: **security@niyamit.com**

Please include:

- A description of the issue and its impact
- Steps to reproduce, or a proof of concept
- Affected version(s) and environment

## What to expect

- We acknowledge reports within **3 business days**.
- We aim to provide an initial assessment within **10 business days**.
- We coordinate a fix and disclosure date with you, and credit you in the
  advisory unless you prefer to stay anonymous.
